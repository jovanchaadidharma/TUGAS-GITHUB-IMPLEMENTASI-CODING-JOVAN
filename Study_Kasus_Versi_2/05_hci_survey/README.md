# 5. HCI & Visualisasi — Survei Kepuasan

## Masalah
Panitia kegiatan ingin memahami penilaian peserta terhadap materi, fasilitas, dan waktu pelaksanaan.

## Metode
Menghitung rata-rata nilai per aspek dan membuat grafik batang. Desain dibuat sederhana agar informasi utama cepat dipahami.

## Menjalankan
```bash
python survey_dashboard.py
```
Script menyimpan grafik `survey_summary.png` di direktori tempat script dijalankan.
