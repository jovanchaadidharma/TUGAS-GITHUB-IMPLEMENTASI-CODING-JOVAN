# 4. Machine Learning — Kategori Kualitas Udara

## Masalah
Contoh sistem pemantauan ingin mengelompokkan kondisi udara ke kategori rendah, sedang, atau tinggi berdasarkan dua fitur sensor sintetis.

## Metode
Model K-Nearest Neighbors (KNN) dengan StandardScaler. Data hanya contoh kecil untuk mempraktikkan alur ML.

## Menjalankan
```bash
python air_quality_knn.py
```
Jangan gunakan model ini untuk peringatan kesehatan atau keputusan lingkungan nyata.
