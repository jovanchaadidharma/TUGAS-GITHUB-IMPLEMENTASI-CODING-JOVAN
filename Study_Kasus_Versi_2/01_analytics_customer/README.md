# 1. Analytics & AI — Segmentasi Pelanggan

## Masalah
Toko online ingin membedakan pelanggan yang sering berbelanja dari pelanggan yang jarang bertransaksi agar promosi dapat disesuaikan.

## Metode
Menghitung frekuensi transaksi dan total belanja, lalu memberi kategori pelanggan dengan aturan sederhana.

## Menjalankan
```bash
python customer_segments.py
```
Data pelanggan dibuat secara sintetis untuk demonstrasi.
