# Study Kasus Versi 2 — AI, Data, HPC, GIS, dan HCI

Versi ini berbeda dari paket pertama: enam studi kasus menggunakan masalah, dataset sintetis, dan pendekatan implementasi yang berbeda.

## Daftar proyek
1. Analytics & AI: segmentasi pelanggan sederhana berdasarkan transaksi.
2. HPC: pemrosesan data sensor dalam beberapa bagian dan perbandingan serial/paralel.
3. GIS: menentukan titik layanan terdekat dari beberapa titik permintaan dengan jarak Haversine.
4. Machine Learning: memprediksi kategori kualitas udara dari data contoh.
5. HCI & Visualisasi: dashboard ringkasan nilai survei kepuasan berbasis grafik.
6. Deforestation & AI: menilai tingkat prioritas pemeriksaan perubahan tutupan lahan berdasarkan fitur sintetis.

## Persiapan
Gunakan Python 3.10+ dan instal dependensi:
```bash
pip install -r requirements.txt
```
Lalu buka folder proyek dan jalankan script yang tercantum pada README masing-masing.

Semua data dalam paket ini sintetis untuk latihan, bukan data resmi atau hasil observasi lapangan.
