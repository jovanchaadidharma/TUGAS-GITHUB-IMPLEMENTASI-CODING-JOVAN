# 3. GIS — Menentukan Titik Layanan Terdekat

## Masalah
Pengelola ingin mengetahui pos layanan mana yang paling dekat dengan beberapa titik permintaan.

## Metode
Menghitung jarak garis-besar menggunakan rumus Haversine dari koordinat contoh. Hasil ini bukan jarak rute jalan.

## Menjalankan
```bash
python nearest_service.py
```
Koordinat bersifat ilustratif dan tidak ditujukan untuk navigasi nyata.
